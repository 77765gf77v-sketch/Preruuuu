# For My Prerana ❤️ — apology website ## Preview on your device 1. Open `index.html` in a web browser. If your phone won't open local HTML files easily, use a computer or publish it using the steps below. ## Publish a real public link (free with GitHub Pages) 1. Sign in to GitHub or create an account at https://github.com. 2. Create a **new public repository** named `for-prerana` (or any name you like). 3. Upload `index.html` to the repository's top level. Keep the filename exactly `index.html`. 4. Open the repository's **Settings → Pages**. 5. Under **Build and deployment**, select **Deploy from a branch**. 6. Choose branch **main** and folder **/(root)**, then save. 7. Wait a few minutes. GitHub will show the published website URL in the Pages section, usually: `https://YOUR-USERNAME.github.io/for-prerana/` 8. Open that URL on your phone to test it, then send the link to Prerana. ## Quick alternative You can also use a static-site host that lets you upload a folder or drag-and-drop files, such as Netlify Drop: https://app.netlify.com/drop. Follow its current sign-in and publishing prompts; the resulting public URL is the one to share. ## Personalizing Edit the text in `index.html` with any text editor. The site is a single self-contained file: no external images, libraries, or build step are required. Note: This page is intentionally gentle and doesn't require Prerana to forgive you or reply. A webpage can open a conversation, but rebuilding trust takes real actions over time.
